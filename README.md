# Deep Residual Image Classification

A PyTorch image-classification project for CIFAR-10, developed and evaluated in Google Colab.

## Verified experiment results

Results from the uploaded notebook's completed run:

- Official CIFAR-10 test images: 10,000
- Test accuracy: 77.90%
- Macro precision: 77.93%
- Macro recall: 77.90%
- Macro F1-score: 77.71%
- Macro ROC-AUC (one-vs-rest): 97.47%
- Macro average precision: 86.15%
- Selected checkpoint: epoch 15

These are measured results for this experiment, not guaranteed results for other environments or runs.

## Dataset and workflow

- Dataset: CIFAR-10 (10 classes, 32×32 RGB images)
- Training/validation split: 45,000 / 5,000 from the original training partition
- Official test set: 10,000 images, reserved for final evaluation
- Data augmentation: random crop, horizontal flip, and color jitter
- Model: custom residual CNN with two residual blocks
- Optimizer: AdamW, initial learning rate 0.001, weight decay 0.0001
- Loss: CrossEntropyLoss
- Scheduler: ReduceLROnPlateau
- Gradient clipping: max norm 1.0
- Training: 15 epochs, batch size 64

## Quick start (Google Colab)

1. Upload `notebooks/DeepLearning.ipynb` to Google Colab.
2. Select **Runtime → Change runtime type → T4 GPU** (or another compatible GPU).
3. Run notebook cells in order.
4. The notebook downloads CIFAR-10 and creates the project outputs in `/content/Deep-Residual-Image-Classification`.

The notebook is the canonical end-to-end workflow. The files in `src/` are extracted reference scripts; because the original notebook initializes shared datasets, model, optimizer, and loaders across cells, run the notebook in order for a reliable end-to-end run.

## Error analysis highlights

The most common confusion was actual `cat` predicted as `dog` (240 test images), followed by actual `dog` predicted as `cat` (129). Cat classification was the most challenging class in this run (F1-score 0.5594).

## Reproducibility notes

The notebook sets random seeds and uses a fixed 45,000/5,000 split. Exact results can vary with hardware, library versions, and nondeterministic GPU operations. Checkpoint and dataset redistribution terms should be reviewed before publishing large binary artifacts.
